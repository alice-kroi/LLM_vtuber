# 外部集成代码规范模板

## 技术栈选择
- 协议：REST / WebSocket / gRPC
- 工具：MCP / Axios / fetch / SDK
- 认证：API Key / OAuth2 / HMAC / JWT
- 容错：重试 / 熔断 / 降级

## 项目结构
```
src/
├── clients/        # API客户端
├── adapters/       # 服务适配器
├── webhooks/       # Webhook处理
├── auth/           # 认证模块
├── cache/          # 缓存策略
├── rate-limiter/   # 限流器
├── config/         # 外部服务配置
└── types/          # 类型定义
```

## 编码规范

### API客户端
- 统一的请求封装
- 自动重试（指数退避）
- 请求/响应日志
- 错误码映射

### 认证处理
- Token自动刷新
- 请求签名
- 凭证安全存储
- 权限范围管理

### 容错机制
- 重试策略：3次，指数退避
- 熔断：连续失败5次后熔断
- 降级：缓存或默认值
- 超时：单次请求30s
