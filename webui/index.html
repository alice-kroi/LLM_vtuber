📖 上下文控制说明
1. Token 控制
限制发送给 LLM 的 Token 数量，避免超出模型限制，同时控制成本。
2. 历史压缩
当对话历史过长时，自动将早期对话压缩为摘要，保留关键信息。
3. 智能选择
根据相关性、重要性、时效性选择最相关的历史消息。
4. 优先级管理
系统提示 > 身份设定 > 知识库 > 长期记忆 > 短期对话。
